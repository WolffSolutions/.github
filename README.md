# .github

This repository powers the **Wolff Solutions** GitHub organization profile.

GitHub renders [`profile/README.md`](profile/README.md) on the organization's
public page at <https://github.com/WolffSolutions>. Edit that file to change
what visitors see.

Org-wide community health files (issue templates, `CODE_OF_CONDUCT.md`,
`CONTRIBUTING.md`, etc.) can also live here and apply as defaults across all
WolffSolutions repositories.
